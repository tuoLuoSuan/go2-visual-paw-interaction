# v0.3.0 — Author manuscript synchronization

Date: 2026-09-20. This release synchronizes the public research package with
the current author-prepared manuscript version. It does not change the robot
controller or report new experiments.

## Added

- Nine-page JPCS-layout author PDF for CC178 and a self-contained LaTeX source
  package under `docs/manuscript/`.
- A manuscript README that states the publication and evidence boundaries.
- Updated paper index and data-availability notes, including the organizer's
  8–10 page expansion context.

## Evidence and boundaries retained

- FORMAL-02 remains ten commanded prone trials: observer-rated contact and
  hold 10/10, clean execution 9/10, one tracking-error abort, and paw
  selection not measured from the lateral view.
- Standing remains a separate qualitative extension and is not pooled with the
  prone denominator.
- MLP/GRU checkpoint comparison remains descriptive, with one training seed
  per architecture and unequal training origins; no significance claim is
  added.
- The PDF is an author version, not proof of publication, DOI assignment or
  EI indexing. Acceptance materials, registration/payment records, raw videos,
  participant materials, private settings and third-party model assets remain
  excluded.
