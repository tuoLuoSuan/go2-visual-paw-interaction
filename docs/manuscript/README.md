# CC178 author version

This directory contains the author-prepared nine-page JPCS-layout manuscript
and its self-contained LaTeX source package. It is shared for reading and
research discussion. The file is not a publisher-formatted proceedings PDF,
and its presence does not establish publication, DOI assignment or EI
indexing.

The expansion adds method and evidence-reporting detail to meet the organizer's
8–10 page suggestion. It does not add real-robot trials: the prone denominator
remains ten commanded trials (10/10 observer-rated contact and hold, 9/10
clean execution, 10/10 safe withdrawal), and the standing recordings remain a
separate qualitative extension. Raw videos, participant materials, private
configuration, third-party hand-model assets and calibration files are not
included.
